# 王者荣耀/三角洲/和平精英电竞护航游戏俱乐部约玩代练录单报单派单打手接单管理系统

源码获取：ym7k.com/19849/

王者荣耀、和平精英、三角洲行动这类热门游戏的代练、护航、陪玩俱乐部，长期面临订单流转混乱：客户下单后手工登记、派单靠微信群、打手接单状态不透明、对账结算麻烦、容易出现丢单、错单、结算扯皮。这套电竞游戏俱乐部管理系统，专门针对游戏陪玩、护航、代练业务打造，覆盖客户下单、录单报单、管理员派单、打手接单、进度跟进、结算对账全流程，是电竞工作室、俱乐部内部业务管理底座，也可对外做成约玩接单平台。

## 技术架构

主流采用 FastAdmin + ThinkPHP 后端，搭配 UniApp 小程序 / H5，PC 后台用于总控管理；分为管理员端、客户端、打手端。源码私有化交付，支持二次开发，可按需调整游戏品类、订单类型、结算规则。

- PC 后台：游戏配置、套餐管理、订单审核、派单、财务结算、打手管理、提成设置、数据统计；
- 客户小程序 / H5：选择游戏、服务类型、下单、查看订单进度、上传段位截图、评价；
- 打手端（H5 / 小程序）：接收派单、抢单、上报进度、上传战绩截图、提交完工、查看结算流水。

## 核心业务模块拆解

### 1. 游戏与服务套餐配置

后台可添加多款游戏，支持王者荣耀、和平精英、三角洲行动等；自定义服务分类：代练、上分护航、陪玩、排位、巅峰赛、陪练、车队、代打任务等。
可设置分段套餐、价格表，比如王者段位套餐、三角洲段位护航套餐；支持区分不同大区、服务器、模式，设置是否需要押金、客户需求备注项。支持上架不同规格的商品套餐，客户直接选择下单。

### 2. 订单录入、报单录单（两种模式）

两种接单模式适配俱乐部业务：

1. **客户自助下单**：客户在小程序选游戏、选服务、填写账号信息、需求、目标段位，提交订单并支付；
2. **后台人工录单报单**：客服线下微信接单后，在后台快速录入订单，也就是俱乐部常用的 “报单”，适合私域来单，是工作室高频功能。

订单支持上传初始段位截图、需求截图，记录客户 ID、区服、目标段位、截止时间、特殊要求。订单状态流转：待派单→待打手接单→进行中→验收中→已完成→售后 / 撤销。

### 3. 派单、抢单双模式

- **管理员派单模式**：后台管理员根据打手擅长游戏、擅长段位、空闲状态，手动指派订单给指定打手；适合管控严格的俱乐部，优先保证服务质量。
- **打手抢单模式**：订单放入抢单大厅，符合条件的打手自主抢单，适合大量散单、打手较多的工作室。
支持设置打手接单权限，限制打手只能接指定游戏、指定段位类型的订单。

### 4. 打手进度上报、战绩回传

打手接单之后，可以在端内上报进度：当前段位、进度说明，上传战绩截图、结算截图。
客户和管理员可以实时查看订单进度，避免打手失联、进度无法追溯。订单完成后，打手提交完工，上传完工截图，等待客户验收。客户确认验收后，订单闭环。

### 5. 财务结算、打手提成、对账体系

这是俱乐部最核心的模块。后台预设提成规则：不同游戏、不同订单类型，打手提成比例固定或自定义；订单验收完成，自动核算打手收入、平台 / 俱乐部利润。
支持打手钱包、提现申请、管理员审核提现；完整流水：订单金额、提成、已结算、待结算、已提现。可以按时间段、按打手、按游戏导出对账报表，解决传统微信对账、手工记账容易出错、结算扯皮的痛点。
支持押金管理、售后扣款、差评扣款配置。

### 6. 打手档案、资质、评分管理

后台建立打手档案，记录擅长游戏、擅长位置、段位、接单上限、历史接单记录、好评率、差评记录、违规记录。
客户订单完成后可以打分评价、写评语，评价展示在打手主页，方便派单管理员参考，也给客户挑选打手提供依据。支持打手黑名单，违规打手限制接单。

### 7. 售后、申诉、风控管理

支持售后工单，客户验收后出现掉分、翻车等问题，发起售后申诉，管理员介入仲裁，配置售后扣款规则。
系统留存全部订单日志、截图记录、操作记录，作为纠纷凭证；支持敏感词过滤、订单备注留痕。

### 8. 数据看板与运营统计

后台可视化看板：订单总量、各游戏营收、打手接单量、完成率、差评率、每日营收、提成支出。支持多维度筛选，统计爆款服务、高产出打手，方便运营调整定价和人员安排。

### 9. 扩展营销能力（可选）

客户端支持优惠券、会员折扣、分销推广，老客户推荐下单返佣；适合俱乐部做私域引流拓客。

## 适用场景与边界提示

✅ 适合：游戏电竞俱乐部、游戏陪玩工作室、代练工作室、多游戏综合接单团队；服务商给电竞工作室定制这套内部派单管理系统。
⚠️ 重要风险提醒：
游戏代练、账号代打，多数游戏用户协议明确禁止代练、账号共享行为，存在账号封禁风险；运营方需要知晓相关游戏规则，平台仅作为内部业务管理工具，不鼓励、不纵容违规代练业务，运营责任由使用方自行承担。
系统只是**订单、派单、财务的业务管理工具，不提供游戏脚本、外挂、科技类能力**。

## 总结

这套电竞俱乐部管理系统，聚焦游戏陪玩护航、代练工作室的真实业务痛点，把录单报单、派单抢单、进度跟踪、截图留档、打手提成结算、对账全部线上化。支持王者、和平精英、三角洲等多款主流游戏，客户端、打手端、管理后台三端协同，替代微信群手工派单和 Excel 记账，减少丢单、结算纠纷，提升俱乐部的接单和管理效率。私有化源码交付，提成规则、订单流程都可以二次定制，是电竞工作室数字化管理的业务底座。
